# Drafts

Handoff for this repo. Chat history is not durable.

## Picking up

1. Read [`HANDOFF.md`](HANDOFF.md).
2. Skim the latest `YYYY-MM-DD-*.md` log if resuming a thread.

## When to write a log

After a session that changes the repo or makes a project decision.

Filename: `YYYY-MM-DD-short-topic.md`.

```markdown

kind: new-work | correction | feedback | notes | housekeeping

## Trigger
```
