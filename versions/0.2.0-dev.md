- **Config preset:** `configs/calibrated_2024.json`.
- **Docs:** `docs/calibration.md` (methods, fits, cross-domain table, gap register); updated `docs/technical.md`, `docs/limitations.md`, `reports/validation.md`.
- **Provenance:** expanded `provenance.json` / `make_provenance.py`.
- **Tests:** 19 unit tests (was 16), including calibration-related checks per `reports/validation.md`.

## Reported gaps (headline)

Not closed in this version—full table in `regional_sim/docs/calibration.md`:

- Real feeder/topology, customer-class mix, and hourly interruption trajectories (electricity).
- FDIC-style **behavioral** heterogeneity (e.g. insured vs uninsured withdrawal)—**not** addressed in this calibration pass (mobility + one power case only).
- Payments, retail spoilage, communication impressions, clinic/water outcomes: mechanism runs but **no** external magnitude match; several cross-domain deltas **flip sign across seeds**.
- Generic stochastic severe-shock generator still uncalibrated.
- **Not** a world-freeze release under [`../INSTRUCTIONS.md`](../INSTRUCTIONS.md) (magnitudes partial, many domains gap-listed).
