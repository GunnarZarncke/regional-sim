# RegionalSim 0.4.0-dev

**Date:** 2026-10-24  
**Status:** Communication-aware commute and relocation **travel** (route/time revision, official road notices, peer relocation plans on route only); Fix I-5 marginal transfer; **no medical** calibration. Not independently validated or frozen.

## Instruction to the coding agent

Verbatim follow-up (relative to 0.3.1-dev):

> commute and relocation seem common areas where people will respond to information or coordinate - think of road closure announcements. implement and calibrate these. let's exclude medical.

## What changed from 0.3.1-dev

- **`road_closure` shock** — main corridor only; opt-in via `configs/road_closure_information.json`; zone-local delayed official `road_closure` / `road_reopened` messages; separate alternate corridor capacity.
- **Policy travel revision** — informed commuters may shift departure (~2.5h) or use alternate route; cancel/revise deferred commute, relocation, return; firsthand `road_delay` reports cannot claim closure.
- **Peer coordination (limited)** — direct contacts' relocation **plans** (with route, TTL) can influence **route** only when the participant already intends to relocate; no peer effect on leave/return probability.
- **Calibration:** `scripts/calibrate_travel_information.py`, `benchmarks/travel_information_observations.json`, `calibration/travel_information_results.json`; marginal targets **48% avoid rush hour / 44% route change** from Ye, Mokhtarian & Circella (Fix I-5 Sacramento), applied conditional on message-informed first commute choice (transferred, not causal messaging effect).
- **Docs / reports:** `docs/travel_information.md`, `reports/travel_information_validation.md`, `reports/road_closure_10000_3d/` example run.
- **Tests:** 44 total (`tests/test_travel_communications.py` + existing suite).

Prior shock proxy (0.2) and availability anchors (0.3) remain; relocation propensity still uses Sue Wing stated-intent thresholds, not peer messages.

## Calibration summary (commute)

| Target | Source | Model check (3 seeds, n=3000, 3-day closure) |
|--------|--------|-----------------------------------------------|
| 48% avoid rush hour | Fix I-5 survey marginals | ~48.9% shift among first **message-informed** commute requests (range ~47.2–51.0%) |
| 44% route change | Same | ~45.4% route among same cohort (range ~44.7–46.6%) |

Independent Bernoulli propensities per commuter (C-level); not a joint distribution or treatment effect of receiving notice. Khattak et al. coefficients **not** transferred.

## Side effect on availability regression

`validate_availability` after travel changes: **31.75%** away at 24h vs 33% anchor (−1.25 pp); **82.69%** at 336h vs 83% (−0.31 pp). Parameters **not** retuned to hide drift; see `docs/travel_information.md`.

## Explicit exclusions

- No medical outcomes, clinic calibration, or health-related messaging effects (per prompt).

## Gaps (headline)

- No randomized/observed **effect of message delivery** on commute or relocation.
- Fix I-5 → Columbus transfer unvalidated; two-link corridor is synthetic.
- Peer relocation route influence is C-level; evacuation literature not used as coefficients.

## Reproduce

```bash
cd regional_sim
pip install -e .
python -m unittest discover -s tests -v
python -m scripts.calibrate_travel_information
python -m scripts.validate_availability
regional-sim --households 10000 --days 3 --seed 47 \
  --shock-json configs/road_closure_information.json --no-availability \
  --sample-rate 0.002 --out output/road_closure
```
