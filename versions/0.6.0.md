# RegionalSim 0.6.0

**Date:** 2026-11-10  
**Status:** World-model mobility and purchase-interface update. Recalibrated
`free_flow_minutes` to **morning one-way** `commute_arrival` minutes vs ACS.
`world_freeze_bar_met` remains **false**.

## What changed from 0.5.2

- Place state for onsite workers: `home` → `to_work` → `at_work` → `to_home` → `home`.
- `Observation`: `at_home`, `at_work`, `hours_since_home_arrival`, `pending_commute_home*`.
- Action `commute_home`; scripted policy requests it after an 8 h C-level shift.
- Morning `commute` requires `at_home` and 7 h since last `commute_home` arrival.
- Shopping, clinic, and buy retries require `at_home` (not merely in-region).
- Buy payload `electronic_only` disables cash fallback at the store.
- `mean_morning_commute_minutes` in daily snapshot; `scripts/calibrate.py` fits on that metric.

## Reproduce

```bash
cd regional_sim
python3 -m venv .venv && .venv/bin/pip install -e .
.venv/bin/python scripts/calibrate.py   # optional; committed artifacts already updated
.venv/bin/python -m unittest discover -s tests -v
```
